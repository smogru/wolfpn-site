# WolfPN — изображения лендинга

- `wolf-brand.webp` — основной логотип сайта.
- `hero-hand-left.webp` и `hero-hand-right.webp` — руки для больших экранов.
- `hero-hand-left-mobile.webp` и `hero-hand-right-mobile.webp` — облегчённые версии для телефонов.
- PNG-файлы сохранены как исходники для будущего редактирования.

Интерфейсы смартфонов отрисовываются средствами HTML и CSS, поэтому дополнительные изображения для них не требуются.
