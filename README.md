# WolfPN

Адаптивный лендинг VPN-сервиса WolfPN с тарифами, сравнением, FAQ и двумя вариантами подключения.

## Возможности

- адаптивная версия для компьютеров и телефонов;
- полноэкранное мобильное меню;
- тарифы «Стандартная», `Unblock` и «Безлимитный Unblock»;
- окно подключения через Telegram-бота или регистрацию на сайте;
- ссылки на поддержку WolfPN;
- облегчённые WebP-изображения и упрощённые мобильные анимации для плавной прокрутки.

## Запуск на компьютере

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который появится в терминале.

## Основные файлы

- `app/page.tsx` — содержимое и логика страницы;
- `app/globals.css` — дизайн, адаптивность и анимации;
- `app/layout.tsx` — метаданные сайта;
- `public/media/` — логотип и изображения рук.

Сайт собран на React, Next.js и Vinext. Репозиторий можно подключить к подходящему сервису размещения или использовать как резервную копию исходного кода.
